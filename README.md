# ♟️ Juego de Ajedrez Neón & Entrenador IA - Breakpoint Creativa

Un moderno juego de Ajedrez web interactivo con diseño estético *Dark Neon*, oponente con Inteligencia Artificial (algoritmo Minimax con poda Alfa-Beta), piezas 3D Staunton fotorrealistas y asistente/entrenador virtual en tiempo real.

Desarrollado por **Breakpoint Creativa** ([www.breakpointcreativa.com](https://www.breakpointcreativa.com)), fundado por **Gustavo Rojas** y **Carolina Riveros**.

---

## 🌟 Características Principales

- 🎨 **Diseño Visual Neón / Dark Purple**: Interfaz responsiva adaptada a 100vh sin scroll.
- ♟️ **Piezas Staunton 3D Fotorrealistas**: Piezas blancas de mármol y negras de negro azabache sólido con contraste perfecto.
- 🤖 **Oponente IA con 3 Niveles de Dificultad**: Fácil, Medio y Maestro (Minimax + Alfa-Beta + Tablas Pieza-Casilla PST).
- 💬 **Asistente & Tutor de Ajedrez (Breakpoint Creativa AI)**: Responde dudas sobre reglas, movimientos de piezas y análisis de partida.
- 📊 **Análisis Técnico Pospartida**: Informe detallado al concluir la partida (resultado, jugadas, aperturas y consejos tácticos).
- 🔄 **Controles Interactivos**:
  - **Voltear Tablero**: Juega como Blancas o Negras.
  - **Nueva Partida** & **Deshacer Movimientos**.
  - **Historial de Movimientos PGN ("MOVIMIENTOS")**.
  - **Efectos de Sonido Sintetizados** (Web Audio API).

---

## 🛠️ Tecnologías Utilizadas

- **HTML5 & CSS3**: Estilos personalizados en CSS puro (Grid, Flexbox, variables CSS).
- **JavaScript (ES Modules)**: Lógica principal de la aplicación.
- **Chess.js**: Motor de validación de reglas de ajedrez (FEN, PGN, jaques, enroques y movimientos legales).
- **Vite**: Bundler y servidor de desarrollo ultra rápido.
- **Web Audio API**: Síntesis de sonido para movimientos, capturas y jaques.

## 🚀 Cómo Ejecutar el Proyecto Localmente

1. **Clonar el repositorio**:
   ```bash
   git clone https://github.com/tu-usuario/juego-ajedrez-breakpoint.git
   cd juego-ajedrez-breakpoint
   ```

2. **Instalar dependencias**:
   ```bash
   npm install
   ```

3. **Ejecutar en modo desarrollo**:
   ```bash
   npm run dev
   ```
   Abre [http://localhost:3000](http://localhost:3000) en tu navegador.
